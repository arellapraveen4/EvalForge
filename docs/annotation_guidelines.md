# Annotation Guidelines

1. Read the complete prompt before evaluating either response.
2. Judge factual correctness and instruction adherence independently.
3. Select only relevant rubric dimensions.
4. Use 1 for severe failure and 5 for excellent performance.
5. Mark factual, reasoning, instruction, omission, relevance, code, formatting, safety, contradiction, and verbosity errors with evidence.
6. Provide a concise rationale that identifies the decisive evidence.
7. Do not let response position, style, or length override correctness.
8. Preserve confidence as a measure of your own assessment, not as proof of ground truth.
9. Do not revise a completed annotation without retaining the previous revision.
